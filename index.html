🔧 One-Time Firebase Setup

To enable real-time chat, leaderboard, and multiplayer, you need a free Firebase project. This takes about 3 minutes.

1. Go to: console.firebase.google.com
2. Click "Add project" → name it anything
3. Disable Google Analytics → Create project
4. Click "Web" icon (</>) → Register app
5. Copy the firebaseConfig values below
6. In Firebase: Build → Realtime Database
   → Create database → Start in test mode
7. Build → Authentication → Get started
   → Email/Password → Enable → Save
